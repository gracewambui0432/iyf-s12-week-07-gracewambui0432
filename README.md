## How to Run

1. Clone the repository:

```bash
git clone https://github.com/gracewambui0432/iyf-s12-week-07-gracewambui0432.git
```

2. Open the project folder.
3. Install dependencies:

```bash
npm install
```

4. Open `index.html` using Live Server.

To run tests:

```bash
npm test
```

To check code quality:

```bash
npm run lint
```
